# Mobile frontend

Install and start:

```bash
npm install
npm run start
```

For Android emulator use `EXPO_PUBLIC_API_BASE_URL=http://10.0.2.2:8000`. iOS simulator and browser can use `http://localhost:8000`. A physical phone must use your computer's reachable LAN address, such as `http://192.168.1.10:8000`; phone `localhost` means the phone itself.
